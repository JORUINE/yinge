一、AI Key：今晚 10 分钟（不用等服务器）

我们代码里已经写好的口径（不用你改代码，照填就行）：
环境变量填什么
DASHSCOPE_API_KEY控制台里复制的那串（sk- 开头）
QWEN_MODEL默认 qwen-plus（想更便宜可换 qwen-flash）
QWEN_BASE_URL默认 https://dashscope.aliyuncs.com/compatible-mode/v1（北京地域）

位置：backend/.env（这个文件已被 .gitignore 排除，不会进仓库）。

  • ① 开通百炼
    打开 bailian.console.aliyun.com， 用你的阿里云账号登录 → 按提示开通「大模型服务平台百炼」。
    算成功：能进到百炼的控制台首页。
  • ② 建 API Key
    控制台右上角确认地域 = 华北2（北京）（我们默认 Base URL 就是这个地域）→ 左侧「API-KEY」→ 创建 API Key → 归属账号选「阿里云账号（主账号）」→ 权限选「全部」→ 确定 → 复制那串 Key。
    官方文档：获取与配置 API Key（2026-10-21 更新）
    ⚠️ 地域不能混用：北京建的 Key 配上海的 Base URL 会报错。
    算成功：列表里出现一串 sk- 开头、点眼睛能看全的 Key。
  • ③ 先用命令行验一下这串 Key 能不能用
    在 Git Bash 里跑（把 sk-xxx 换成你的）：
    export DASHSCOPE_API_KEY='sk-xxx'
curl -s https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-plus","messages":[{"role":"user","content":"说一句话"}]}'
    算成功：返回的 JSON 里有 "choices" 和一段中文；不是 "code":"InvalidApiKey"。
  • ④ 填进 backend/.env 并重启后端
    找到这一行，把 Key 贴在等号后面（不要加引号、不要留空格）： 
    DASHSCOPE_API_KEY=sk-你自己的那串
    保存 → 停掉后端 → 重新 npm run dev（或 node src/server.js）。
    算成功：做一次人格测评，解读文字是"像人写的一段评语"，而不是套模板的几句话。
  • ⑤ 不用管的三件事（代码里已经做好了）
    ① 每人每天最多真调 5 次（LLM_DAILY_LIMIT），防别人刷爆你的额度； ② 连续失败 3 次自动熔断 10 分钟；③ 同一个人同类型同分数直接复用上次解读。
    就算 Key 没填、或额度用完，功能也不会报错，会自动降级成模板文案。
关于"免费额度"：新账号通常有每个模型的免费额度，但额度和有效期会变， 我不在这里写死数字 —— 以控制台「费用与额度」页显示为准。够我们做毕设演示 + 答辩，正常用不完。

二、服务器：今晚/明晚 1 小时（先买香港）

为什么先买香港：国内节点必须备案才能用域名访问（备案 7~20 天）； 香港节点免备案，买完当天就能把 IP 发给老师/同学看。
  • ① 实名认证
    阿里云控制台右上角「头像 → 实名认证」→ 个人认证（身份证 + 人脸）。 姓名必须和后面备案、域名实名用同一个，错一个字整套要重来。
    算成功：账号状态显示「已实名」。
  • ② 学生认证 / 领券（能省不少）
    搜「阿里云高校计划」做学生认证（学信网/学生证），再进「权益中心」把能领的券都领了。 具体券面额以活动页当天显示为准，我不替你承诺金额。
    算成功：权益中心里能看到"已领取"的 ECS 代金券。
  • ③ 买香港 ECS
    ECS 购买页 → 地域：中国香港 → 实例规格选最便宜的一档（1~2 核 2G 足够） → 镜像：Ubuntu 22.04（或「宝塔面板」镜像，图形化管理更省事）→ 系统盘 40G → 带宽按量/固定 1~3M 都行（我们页面很轻）→ 购买。
    参考价位（2026-10 记录，以官网当日活动为准）：新用户常见 60~100 元/年 档。 价格页：阿里云产品定价
    算成功：控制台「实例」里有一台运行中的机器，能看到公网 IP。
  • ④ 开放端口 + 拿到登录方式
    实例 → 安全组 → 入方向放行 22（SSH）、80（HTTP）、443（HTTPS）； 记下：公网 IP、root 密码（或密钥）、地域、到期日。
    算成功：本地 ssh root@你的IP 能登录进去。
不要做的事：别买"云虚拟主机"（不能装 Node）、别买 Windows 系统（贵且吃内存）、 别选 4G 以上高配（我们整库才十几 MB，纯浪费）。

三、国内机器 + 域名 + 备案：今晚提交，剩下的交给时间

  • ① 买一台国内 ECS（备案要用）
    地域选离你近的（如成都/重庆/深圳）。关键限制 购买时长必须 ≥ 3 个月才能办备案 —— 直接买一年最省事。
    算成功：控制台里有一台包年包月的国内实例。
  • ② 买域名 + 域名实名
    万网/域名注册 搜一个短一点的名字。 .cn 与 .com 都行；用同一个身份证做域名实名，通常几小时到 1 天。
    ⚠️ 买完先别解析 —— 备案没通过就解析，会被监测到未备案而阻断，反而添乱。
    算成功：域名列表里状态是「实名认证成功」。
  • ③ 提交 ICP 备案
    进 beian.aliyun.com → 用买了国内机器的那个账号登录 → 开始备案 → 主体信息（身份证）→ 网站信息（名称、服务内容选"个人博客/其他"）→ 上传资料 → 手机核验 → 提交。管局审核约 7~20 个工作日（各省不同）。
    官方查询入口：工信部备案系统
    算成功：阿里云后台显示「已提交，待管局审核」，你会收到短信。
  • ④ 备案期间（等着的这十几天）干什么
    正好是我这边推进的时间：香港机上把站点跑通 → 录演示视频 → 写论文正文。 不要干等，备案是最不该占用你注意力的那件事。
  • ⑤ 备案通过之后
    拿到备案号（形如 蜀ICP备2026XXXXXX号）→ 把域名解析到国内机 → 把备案号发我，我加到页脚（法规要求必须挂）。
    算成功：https://你的域名 能打开，页脚有备案号。

四、你要发给我的 5 样东西（发我之后我来配）

#东西用途

五、上线时容易踩的 8 个坑（提前知道就不会卡住）

坑怎么躲
备案期间解析域名先别解析，等备案号下来再解析
JWT_SECRET 还用本地那个线上必须换新随机串（生成命令在 .env.example 里）
CORS_ORIGINS 没加线上域名填 https://你的域名，否则前端请求全被拦
MongoDB 用本地 127.0.0.1线上要么装本机 MongoDB，要么用 Atlas 连接串
服务器内存 1G 跑不动2G 起步；MongoDB 会吃内存
安全组没开 80/443买了机第一时间放行
把 .env 提交进 git仓库已忽略，但不要手动 git add -f
以为"有 IP 就能给人看"国内机没备案，用 IP 访问 80 端口会被拦
