本轮（9/18）新修 —— 对应你最新这组 10 张截图

  • 投票卡死（最严重）：根因是游客投满 50 票后被"新账号大量投票"规则误判为异常 → 该票作废且本场不推进 → 再点就报"已投过这一场"，彻底进退不得。修法：① 游客不再参与异常判定 ② 异常票照样推进赛程、只是不进排行榜 ③ 前端遇到"已投过"直接刷新进下一场 + 防连点。实测：整场 5 票跑通、重复投票返回 3001。
  • 小组赛试听：以前只拉 1 首"主打"，播放条永远显示 1/1、上一首/下一首全灰。已改为与淘汰赛同一套：拉整张专辑曲目、可逐首切歌、显示序号。
  • 对位赛显示"本轮出战 0 张"、没有盲盒：根因是对位赛没算进"本轮张数"。已修 —— 现在正确显示张数，并出现盲盒虚位卡（模糊堆叠 + 省略号 + "还有 N 张"）。
  • 收藏只做专辑：按你的要求去掉"人格类型"收藏与筛选，收藏页只留专辑。
  • 自选专辑上限 100 张：前端拦截 + 后端校验；并补上"同一歌手可能在某一轮内战（同室操戈）"的声明（模式说明 + 手动挑选页）。
  • "加载其专辑"没反馈：现在点一下会弹「已添加 XX 的 N 张专辑」提示，新加入的卡片带入场动画。
  • "我的对决"列表封面全裂：根因是接口从不返回封面。已补（批量取每场第一张专辑封面）+ 无封面时占位图标。
  • Edge 最小化闪屏 / 偶尔卡住：根因是"铺满视口的固定层 + blur(100px)"让浏览器合成器持续重绘。已把极光背景改成径向渐变（零 blur），并在 Edge 下关掉所有毛玻璃与大 blur —— 既治闪屏也提性能。
  • 颜色硬化：浅色 / 暖白封面不再硬凑彩色（避免白底封面跑出粉、紫），饱和度上限 48%→40%。

本轮（9/18 第二批）新修 + 立规则

  • 游客不再被任何规则限制：① 上一条已把"投满 N 票"误判修掉；本轮再进一步 —— 风控只把可疑票排除出排行榜，不再累计违规、不再限流/封号。你可以理解为：不注册也能把主线玩到底，永远不会因为"玩得多"被拦住。
  • 游客醒目提醒：顶栏下方新增常驻提示条 —— 明确写"不注册也能玩全部主线；但游客数据只存本机浏览器，注册后可云同步/收藏/上榜" + 注册按钮。
  • 游客数据迁移（A-07）已实现：注册或登录后自动把本机游客账号的对决 / 票 / 测评 / 收藏转到你的账号（真后端 E2E 实测：迁移 1 场对决 + 权限随账号走 ✓；游客自己发起会被拒 ✓）。
  • 点试听误投票：给整卡加"点封面即投票"后，卡内「试听 30 秒」没有阻断冒泡 → 点试听等于投票。已 @click.stop 修掉，并立规则"可点卡片内的次级按钮必须阻断冒泡"。
  • 切歌键图标：小组赛播放条的"下一首"用了"上一首"的图标，已换成正确的 ▷|。
  • 多歌手只选 1 位时没盲盒：totalSelected 里 picked.length < 2 → return 0 又被写回（守则 43 的同类回归）。已修，并立规则"开局门槛与预览计数必须分开算"。
  • 小组赛卡片（多组挤压）：8 组时卡片被挤成一条、封面变指甲盖。根因是 repeat(auto-fit, minmax(0,1fr)) 没有最小列宽。已改为可读最小宽度并换行，并写进守则第 70 条。
  • Edge 最小化（第二次深修）：上一版"减 blur"不够 —— 现在 Edge 下极光整层不渲染，改把海洋蓝光晕画在 body 背景（非合成层），并关掉全部 filter / 毛玻璃。需你在 Edge 实测确认。
  • 取色兜底改品牌蓝灰：取不到彩色时不再用中性灰，改成与海洋蓝同色域的蓝灰，保证背景调性统一、海蓝依然好看。
