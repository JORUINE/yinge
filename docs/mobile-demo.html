1三种打开方式（挑一个顺手的）

A

电脑上看「手机版」（最快）

双击项目根目录的 start-mobile-demo.bat，等 10 秒会自动打开网页。 然后按 F12 → 点左上角手机图标（或 Ctrl+Shift+M） → 顶部设备选 iPhone SE 或 Pixel 5 → 刷新。
这就是手机上看到的样子（含底部 Tab、安全区、触控热区）。

B

用真手机访问（最真实）

手机连同一个 Wi-Fi，浏览器打开 http://192.168.1.65:5173（这个 IP 每次可能变， 以黑窗口里打印的那串为准）。
这是真机：有真触摸、真安全区、真拇指操作。推荐用这个验收。

C

看这一页的截图（零成本）

什么都不用装，往下滚就是 11 张真机截图，每张都标了"这里为什么这么放"。
看完想动手了再回 A / B。

如果双击 .bat 没反应 / 打不开： ① 看是不是被杀毒软件拦了（选"允许"）； ② 黑窗口里如果提示端口被占用，先双击 stop-dev.bat 再重试； ③ 手机打不开 —— 确认手机和电脑在同一个 Wi-Fi，且电脑弹出的"Windows 防火墙"提示里勾选了专用网络。 还有问题就把黑窗口里的字发我。

2建议你这样试一遍（3 分钟）

步做什么应该看到什么
1打开首页，看最底部底部 5 个 Tab：首页 / 对决 / 人格 / 排行 / 我的。点每个都能跳，当前项会高亮
2点「开始对决」→ 选「单歌手内战」选完模式，底部自动升起筛选弹层（不用你去找）
3在弹层里搜「周杰伦」候选第一位是曲库里有 17 张专辑的「周杰倫」，不是卡拉OK团（这是本轮修掉的 bug）
4点候选上的「加入」底部那行立刻变成「已选 8 张 · 来自 1 位歌手 · 共 5 场」—— 选了什么看得见
5点「开始对决」先打小组赛（4 张里勾 2 张 → 点确认），进度写在页头
6进淘汰赛左右两张并排，专辑名在封面正下方，试听在专辑名正下方；点封面即投票，点「试听 30 秒」不会误投
7一路打完结果页出冠军卡 + 「生成夺冠之路」；分享页能存图
8回底部 Tab 点「我的」能看到刚才这一局的记录（对决 / 测评 / 收藏 / 组合四个 Tab）
第 3 步是重点：上一轮这里会出 bug——搜「周杰伦」时卡拉OK团「周杰伦战队」排在真歌手前面， 点了之后池子里是一位 0 张专辑的野鸡歌手，摘要永远停在「还没选完」。现在已经修好， 回归探针 12 条断言盯着它，不许再犯。

4这批截图是怎么来的（可信度）

  • 不是设计稿、不是摆拍：从真库真后端真建了一局、真投票打到冠军，一路截过来的。脚本 tools/pw/shot-mobile-demo.mjs。
  • 视口就是真机视口：375×780、isMobile:true、hasTouch:true、2 倍屏 —— 和 iPhone SE / 主流安卓一致。
  • 全程 0 条 JS 错误（截图脚本自己数的）。
  • 唱片封面来自 iTunes（周杰伦《太陽之子》《驚嘆號》《陶喆同名專輯》等），是真实曲库数据，不是占位图。
  • 号码是游客号：这一局是游客身份打的 —— 不注册也能玩全部主线，这条你定的规则本身就是这么展示的。
为什么⑦是左右而不是上下：你原话"专辑对决那里应该是要在下面左右两边分别展示出专辑名字 方便用户点"。 而旧代码在 ≤860px 会把两张卡折叠成上下、还把 VS 藏掉 —— 那是本轮按你意见改掉的部分。 现在左右各占约一半（实测各 137px 同一行、封面不重叠）。
