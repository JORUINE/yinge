2逐条根因与修法

① 选歌手时操作条让位 达成

你要的
蓝框（悬浮操作条）在进入选歌手子菜单后，移到绿框（弹层内容末尾）
原来
.mobar 是 position:fixed 悬浮在屏幕底部上方，盖住弹层正在选的歌手和组合
修法
弹层打开时：① 悬浮条 v-if="!sheetOpen" 让位消失； ② 在 .opts 内容最末尾（"收藏当前组合"之后）渲染 .mobar-in-sheet， 样式沿用同一套圆角玻璃 + 按钮，只是改为跟随内容滚动

③ 毛玻璃 / 背景模糊 达成

原来
.scard.glassy 没有 backdrop-filter （历史备注写"html2canvas 不认，导出会丢掉整层"）⇒ 页面预览没有玻璃透光感
修法
加 backdrop-filter: blur(18px) saturate(170%) + 玻璃高光内阴影。 用 @supports 包住，不支持的浏览器完全不应用。 ⚠️ 那条历史备注针对的是"不能依赖它做视觉"——现在 .sbg（模糊封面底） 和 .glassy::before（配色柔光）已经独立成立，导出时 html2canvas 忽略 backdrop-filter 也不影响成图
验收
cardBackdrop = "blur(18px) saturate(1.7)" 实测生效； .sbg 已加载（data:image/jpeg;base64）

④ 方形图裁字 达成

现象
方形图保存下来，底部「8 强 → 半决赛 → 决赛」和「16 张专辑…」被裁掉
三种写法实测
· min-height: 0 → 卡片钉死 342，内容溢出 220px（裁得最狠）
· min-height: auto → 对非 flex/grid 子项等于 0，同样钉死 342（还是裁）
· min-height: fit-content → 在 overflow:hidden 的卡片上也不生效
根因
.scard 是 overflow:hidden，aspect-ratio 一旦定死高度， 多出来的内容只会被裁，不会撑开
最终修法
放弃严格 aspect-ratio，改成 min-height: 430px： 宽度与竖版相同、高度至少 430、内容多了自动变高 ⇒ 一个字都不裁
验收
方形 342×430（0.795） vs 竖版（0.704）；7 个文字元素 overflow: [] 全在卡内
必须说清的取舍：342px 宽的方卡装不下这套内容 （★冠军★ + 封面 + 名字 + 艺人 + 对手缩略图 + 轮次 + 统计）。 要严格 1:1 且不裁字，只能把卡片内容（字号/封面/间距）整体缩小约 17%—— 那会改变版式观感。按你之前"方形和竖版唯一的区别就是比例"的要求， 我没有自己动字号，选择了保住不裁字、比例做到 0.795（比竖版明显更方）。 要真 1:1 的话你说一句，我就把内容整体缩 17%。
