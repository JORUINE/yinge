阿里云上线全流程手册 · 2026-10-14 · 从选机器到 HTTPS 全覆盖

没做过部署也能照着走完

这份比《连号操作单》更细：选服务器怎么选、备案每步填什么、怎么登上服务器（你没用过 SSH 也写得看得懂）、 怎么装环境、怎么把音格放上去、域名怎么解析、HTTPS 怎么开。九章，按顺序做。

先回答你问的那个我没答好的问题：「还没做的玩法、UI 修复，是先部署还是先修好再部署？」
先部署，修复滚动跟上。理由是三条，都不是"图省事"：
① "修完再上线"是个陷阱 —— 没做的玩法 + UI 修复是个开放清单（7 个 P2 小项 + 深色模式 + 响应式逐页验收）， 永远还有下一项。等"全部做完"的那天永远不会来。
② 现在部署的成本接近零 —— 已经有 push → 自动部署，你改完推一次，几分钟后线上就是新版。部署不是终点，是起点。
③ 备案那 2~5 周不能空着 —— 管局审核时间花钱买不到。那段时间网站应该在给人玩，而不是关着等。

而且我刚才真机量过了：现在就已经达到"敢发链接"的标准。39 项断言全绿 —— 注册 → 建局 → 投票 11 场 → 夺冠 → 晋级图导出成 PNG（1760×1372）→ 测评提交出结果 → 榜单有数据 → 6 型都有推荐专辑； 6 个页面 + 375 手机视口零横向溢出、零破图、零 JS 错误。

所以顺序是：香港机器先上（第 1~7 章）→ 上线后每修一项就 push 一次 → 备案下来迁国内（第 8 章）。
附一条你能自己判断的标准（以后每次想上线前都问自己）
✅ 可以上线主流程走得通（注册→建局→投票→夺冠→分享→测评）；没有白屏/破图/404；文字读得清；手机上能走通。
❌ 不该上线一开局就报错；封面全是破图；分享图存不下来；测评提交失败；手机上页面撑爆。
💡 不影响上线某个锦上添花的小功能没做；某页配色还想再调；某个动画不顺手。这些上线后照样能改。

1选服务器：三个决策，照抄就行

决策点选什么为什么
地域先买中国香港，再买一台国内（如华东/华南）香港免备案、当天能上；国内要备案但速度最快，两台分工
镜像宝塔 Linux 面板（应用镜像分类里）装 Nginx / Node / MongoDB 全是点鼠标，不用记命令
配置2核2G，系统盘 40GB 以上，带宽/流量选最便宜的档实测我们数据才 18MB、后端很轻；2核2G 带 Nginx+Node+Mongo 毫无压力
购买时长香港先买 1 个月试；国内直接买一年国内节点时长 ≥3 个月才能办备案
数量各 1 台一台生产一台备案用，不需要集群
预算合计约 134 元/年：服务器（阿里云轻量新用户 38~99 元/年）+ 域名（.cn 约 29 元/年）。 数据库用服务器上自建的 MongoDB，不用另买云数据库。你有学生认证的 300 元抵扣金，基本等于白嫖。
下单后立刻做的一件事：放行端口。服务器详情 → 防火墙 → 添加规则，放行 80、443、8888（宝塔面板）、22（SSH）、3000。 不放行的话外面打不开，而且不会有任何提示 —— 这是新手最常卡住的地方。

2登上服务器（你没用过 SSH，从这里看起）

两条路，选一条就行。完全不想碰命令行 → 走路 B（网页远程连接）。
路 A · SSH（推荐，后面部署要用）
  1. 拿到 root 密码
    阿里云控制台 → 轻量服务器 → 你的实例 → 重置密码（或查看初始密码）。用户名叫 root。
  2. 打开终端
    Windows 10/11 自带：按 Win 搜 PowerShell 或 终端，打开。
  3. 连接
    输入 ssh root@你的公网IP 回车，第一次问 yes/no 输 yes， 然后粘密码。
    ⚠️ 输密码时屏幕上一个字都不显示，这是正常的，不是卡住了，输完直接回车。
  4. 成功的样子
    命令行前缀变成 [root@xxx ~]#，这就说明你已经在服务器里了。之后所有命令都在这个窗口里执行。
路 B · 网页远程连接（零门槛）
  1. 入口
    阿里云控制台 → 你的实例 → 右上角 远程连接 → 选 通过网页 SSH 连接（或 VNC）。
  2. 登录
    用同样的 root + 密码。浏览器里直接开一个黑窗口，效果和 SSH 一样。
  3. 注意
    网页连接粘贴不方便（有的浏览器要 Ctrl+Shift+V）， 长命令建议先用记事本改好再贴。想长期用还是建议学会路 A，就四步。

3装环境（宝塔面板，全是点鼠标）

  1. 进宝塔面板
    浏览器开 http://你的公网IP:8888。如果进不去，先看防火墙有没有放行 8888。
    ⚠️ 刚买的宝塔镜像可能要求你先在阿里云控制台"远程连接"里执行它给的一条命令来初始化面板，按提示做。
  2. 装三个软件（面板左侧「软件商店」→ 搜索 → 安装）
    ① Nginx（选最新稳定版，如 1.24）
    ② Node.js（版本选 20 或 22，**别选 18**——后端要求 >=20）
    ③ PM2 管理器（在 Node 分类里，装了它会自动带上 PM2）
  3. 装 MongoDB
    软件商店搜 MongoDB，选 6.0 或 7.0 安装。
    ⚠️ 装完默认只监听 127.0.0.1，这正是我们要的（数据库不该暴露到公网），不要改。
  4. 确认版本
    在 SSH 窗口里跑下面三条，看到版本号就行：
# 在服务器的 SSH 窗口里执行
nginx -v          # 应显示 nginx/1.xx
node -v           # 必须是 v20 或更高
pm2 -v            # 应显示 5.x
mongod --version  # 或：mongo --version
如果 node -v 显示 v18：去宝塔"软件商店 → 已安装"找到 Node，卸载后重装 20+。 后端 package.json 里写了 "node": ">=20"，用 18 跑可能莫名报错。

4把代码放上服务器

  1. clone 仓库
    在 SSH 窗口里执行（仓库是公开的，不用密码）：
# 1) 把仓库克隆到 /opt/yinge
mkdir -p /opt && cd /opt
git clone https://github.com/JORUINE/yinge.git
cd yinge

# 2) 建后端环境变量（密钥只在这里，不会进 git）
cp backend/.env.example backend/.env
  1. 填 backend/.env
    用宝塔面板左边的「文件」打开 /opt/yinge/backend/.env 编辑（比 vim 好用），按下面填：
填什么值
NODE_ENVproduction
MONGODB_URImongodb://127.0.0.1:27017/yinge（数据库就在本机，不用 Atlas）
JWT_SECRET新生成的随机串，别用本地那个。生成命令见下
CORS_ORIGINS先填 http://你的公网IP；有域名后改成 https://你的域名
DASHSCOPE_API_KEY有千问 Key 就填；没有就留空（自动走模板文案，功能不报错）
其它（ITUNES_* / CACHE_* / VOTE_*）用默认值，不用改
 
# 生成 JWT_SECRET（输出整串复制走）
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
千万不手动加 PORT。部署脚本会通过 PM2 注入 3000， 你手写一个反而会冲突。也不要把 .env 提交进 git（仓库的 .gitignore 已经排除了，别手动 git add 它）。

5配 Nginx + 首次部署

  1. 放 Nginx 配置
    仓库里已经写好了 deploy/nginx.conf，只需改两处路径/域名：
# 1) 复制配置
cp /opt/yinge/deploy/nginx.conf /etc/nginx/conf.d/yinge.conf

# 2) 改两处（用宝塔「文件」打开 /etc/nginx/conf.d/yinge.conf）
#    server_name _;            →  server_name 你的域名;   （没域名就先留着 _）
#    root /opt/yinge/frontend/dist;  →  按实际路径，通常不用改

# 3) 验语法再重载（不验就 reload，配置写错会让整个 Nginx 起不来）
nginx -t && nginx -s reload
  1. 跑一键部署
    它会自动：拉代码 → 装依赖 → 重建前端 → 启动/重载后端 → 自检。第一次要 2~5 分钟。
# 在 /opt/yinge 下执行
cd /opt/yinge
bash deploy/deploy.sh

# 看到这两行就算成功：
· /health → {"status":"ok"}
· /ready  → {"status":"ok","db":"connected"}

# 设为开机自启（服务器重启也不用你管）
pm2 startup && pm2 save
怎么算成功：浏览器打开 http://你的公网IP/，能看到音格首页，点进去能注册、能建局。 到这一步，香港机器已经算上线了，链接可以发给人玩了。
以后每次更新：你电脑上 git push → 服务器上 bash deploy/deploy.sh（或配了 GitHub Actions 就全自动）。 零停机，用户无感。

6把数据搬上服务器

不做这一步，线上就是个空站：能打开、能注册，但一开局就没专辑、测评没题目、榜单是空的。 因为服务器上刚装的 MongoDB 是全新的空库，你电脑本地那个才有 45064 条数据。

在你电脑的 Git Bash 里跑（把引号换成你服务器的 IP）：

# 先只读演练，看会搬什么
cd /e/桌面/毕业设计/yinge/backend
node scripts/migrate-to-atlas.mjs --from "mongodb://127.0.0.1:27017/yinge"

# 确认无误后真搬到服务器（默认只读演练，加 --apply 才写）
node scripts/migrate-to-atlas.mjs "mongodb://root:你的SSH密码@你的公网IP:27017/yinge" --apply
两个坑：① 如果 MongoDB 只监听 127.0.0.1，外网连不上 —— 临时把 /etc/mongod.conf 的 bind_ip 改成 0.0.0.0，搬完立刻改回来（数据库暴露在公网很危险）； ② 更稳的做法是在服务器本地跑：把本地数据 mongodump 出来传上去，或用宝塔自带的数据库备份恢复。 嫌麻烦就用第一种，但记得搬完把 bind_ip 改回 127.0.0.1 并重启 mongod。
实测参考：14 个集合、45064 条，脚本会逐个核对条数并做外键抽检 （对局 _id、albumIds、userId、冠军专辑、淘汰赛胜方专辑在目标库全能找到才算过）。

7域名解析 + HTTPS

域名解析（10 分钟，随时可做）
  1. 进域名控制台
    阿里云控制台 → 域名 → 你的域名 → 解析。
  2. 加两条 A 记录
    记录类型 A；主机记录一条填 @、一条填 www； 解析值都填服务器公网 IP；TTL 默认。
  3. 等生效
    通常 10 分钟内。生效后 http://你的域名/ 能打开。
  4. 改 Nginx 与 CORS
    把 nginx.conf 的 server_name _ 改成你的域名， reload；再把 backend/.env 的 CORS_ORIGINS 改成 https://你的域名， 然后 pm2 reload yinge-api。
HTTPS（备案通过后才能做）
  1. 为什么必须等备案
    中国大陆服务器 + 域名 + 443 端口，没备案会被厂商阻断。
  2. 用宝塔一键签证书
    宝塔面板 → 网站 → 你的站 → 设置 → SSL → 选 Let's Encrypt → 勾选域名 → 申请。全程点鼠标，免费。
  3. 开强制 HTTPS
    同一个页面打开 强制 HTTPS 开关，之后 http 会自动跳 https。
  4. 验收
    地址栏出现小锁，https://你的域名/ 正常打开。
香港机器可以跳过本章：用 IP + 端口先跑着，等备案下来、迁到国内再补域名和 HTTPS。

8备案（与上面并行，越早提交越好）

这是唯一"花钱也买不到速度"的环节：管局审核 7~20 个工作日（京沪粤可能 20~30 天）。 买完国内机器当天就提交，然后该干嘛干嘛。详细每步填什么见《阿里云连号操作单》，这里只提醒最容易翻车的四点。
环节要点时长
实名 + 买国内机器 + 买域名三个实名主体必须是同一个名字；域名也要实名当天
填备案信息网站名称别用"中国/中华/最"这类词；地址写到门牌号；性质选个人/非经营30 分钟
阿里云初审 + 电话核验电话一定要接，照实说"个人毕业设计作品"；漏接直接退回1~2 工作日
工信部短信核验短信里的链接 24 小时内必须点回去确认，超时自动退回24 小时
管局审核干等。期间可以正常开发，但网站不能开放7~20 工作日
备案成功拿到备案号，挂到网站页脚，然后才能解析域名 + 开 HTTPS—

9上线后：剩下的功能怎么排

原则：上线不是终点。每修好一项就 git push 一次，用户看得见地在变好。 下面是我建议的顺序，你也可以打乱。
顺序事项优先级为什么要这个顺序
1接千问（你实名后去百炼领 Key 发我）P0人格解读从模板变成真定制化，是产品的核心差异点；三道闸已就位，不怕被刷
2深色模式逐页验收P0守则里明确"未逐页验收"，属于欠账；晚上用的人多，体验差一半
3响应式 375/768/1024/1440 逐页过P0手机上才是"更多人愿意玩"的主战场；就绪检查里只测了 375 三个页
4榜单「地区/年代/周期」筛选P1需要后端加接口；有了它榜单才真有用，不然只是摆着
5分享图方形版重做P1方形图在朋友圈/小红书更好发，直接影响传播
6大逃杀 100 张彩蛋P2你说过"正式版做完再议"，现在就是那时候
7专辑/艺术家介绍二级菜单P2你自己说的"整个版本做完再做"
8设计稿 p4/p5/p6 按 v2 重绘P2纯文档对齐，不影响用户
每做完一项的标准动作：本地自检跑绿 → git push → 服务器自动部署 → 用手机流量打开线上地址走一遍那项功能。别只在本地看，线上路径和本地不一样（CDN、HTTPS、跨域）。

10排错对照表

现象八成是这个原因怎么办
SSH 连不上 / 超时防火墙没放行 22；或密码错阿里云控制台放行 22；用"重置密码"重设
输密码时光标不动正常，Linux 输密码不显示任何字符直接输完回车
http://IP:8888 打不开防火墙没放行 8888；或面板未初始化放行 8888；按阿里云"远程连接"里给的命令初始化
nginx -t 报错配置文件写错（路径/分号/花括号）看报错行号；先 nginx -t 通过再 reload，别跳过
网站能开但接口全 404Nginx 的 /api/ 反没配对，或后端没起pm2 status 看 yinge-api 是否 online；pm2 logs yinge-api 看报错
能注册但一开局就没专辑第 6 章数据没搬跑 migrate-to-atlas.mjs；搬完在 mongo 里数 albums 条数
/health 通但 /ready 503数据库连不上看 MONGODB_URI；确认 mongod 在跑（systemctl status mongod）
接口报 CORSCORS_ORIGINS 没填当前访问的域名/IP改 .env 后 pm2 reload yinge-api
刷新页面 404SPA 兜底没生效确认 try_files $uri $uri/ /index.html; 在 location / 里
部署脚本中途失败依赖没装上前端构建失败看脚本输出；它会在"构建后找不到 index.html"时中止且不重启后端
想回退到上一个版本—服务器上 cd /opt/yinge && git log --oneline -5，git checkout <commit> 再跑 deploy.sh
