## 三、复现命令

### 1. 论文 / 开题报告 ★首选

```bash
PY="C:\Users\胡祖锐\.venv-html-to-docx\Scripts\python.exe"
"$PY" tools/md2thesis.py docs/开题报告.md <输出.docx>   # 生成正文 + 目录域 + 页码
"$PY" tools/add_toc.py <输出.docx>                      # 调本机 Word 刷出真实页码
```

**内容源只有一份**：`docs/开题报告.md`。改内容改 md，再跑上面两条命令即可，不用碰 Word。

Markdown 约定：

| 写法 | 生成效果 |
|---|---|
| `# 标题` | Word Title（居中黑体二号，不进目录） |
| `## 章节` | Heading 1（黑体三号，进目录） |
| `### 小节` | Heading 2（黑体四号，进目录） |
| `#### 三级` | Heading 3（黑体小四，不进目录） |
| `> 文字` | 抬头行（封面信息，不缩进） |
| `- 文字` | `[1]` `[2]` 悬挂缩进编号 |
| `[TOC]` | 此处插入目录 |
| `__u{文字}__` | 给「文字」加下划线（填空线） |
| `\| 表格 \|` | 简单表格（带边框） |

## 四、踩过的坑（重要，避免重复）

### 坑 1：HTML 转 DOCX 时表格列宽不受 CSS 控制
- **现象**：给 `<td>` 设 `width` 无效，转换器自行分配列宽，短标签列被压窄而折行。
- **结论**：表单式抬头**不要用多列表格**，改用段落 + `<u>` 下划线。

### 坑 2：段落太长导致的"假折行"
- **真相**：不是表格问题，是整行放不下。A4 + 左右页边距 3.17cm 时正文可用宽度仅 **416pt**；
  一行塞两组"标签+值"约需 372pt，余量仅 10%，字体稍有差异就折行。
- **修复**：一行只放一组"标签+值"（每行约 180pt）。
- **核算公式**：可用宽度 = (11906 − 左右页边距) ÷ 20 pt；行宽 ≈ 全角字数×字号 + 半角字数×字号÷2；**留 30% 余量**。

### 坑 3：Word 每次打开都弹「是否更新该文档中的这些域？」
- **根因**：`html_to_docx` 引擎写入 `<w:updateFields w:val="true"/>`；Word 因此每次询问。
- **修复**：删除该节点。`tools/fix_docx.py` 处理旧链路；`md2thesis.py` 本身就不写它。
- **注意**：**目录、页码这类域不会导致弹窗**（弹窗只由 `updateFields` 触发），
  所以"要目录"和"不要弹窗"不冲突——正确做法是先生成域，再用 Word 更新一次并存盘。

### 坑 4：python-docx 的中文字体必须写三个属性
- **现象**：只设 `run.font.name = "宋体"`，Word 里中文仍显示为等线/Calibri。
- **原因**：`font.name` 只改 `w:ascii`，中文走 `w:eastAsia`。
- **修复**：`w:ascii` / `w:hAnsi` / `w:eastAsia` **三个都设**成同一中文字体名。

### 坑 5：用直接格式做标题 = 丢掉 Word 的语义结构
- **现象**：标题看起来对，但**导航窗格空白、无法插入目录、大纲级别丢失**。
- **根因**：用 `add_paragraph()` 手写黑体+字号，只是"长得像标题"，不是标题。
- **修复**：必须用 `doc.add_paragraph(style="Heading 1")` 等内置样式，
  再改该样式的字体字号。目录只认样式，不认长相。

### 坑 6：行距数值不是"倍数"
- OOXML 中 `w:line` 单位是 **1/240 行**：`240` = 单倍，`360` = 1.5 倍，`480` = 双倍。

### 坑 7：Graphviz 的 HTML 标签里不能有空 `<FONT>`
- **现象**：`Error: syntax error in line 1 ... <FONT POINT-SIZE="9"></FONT>`。
- **修复**：空单元格一律用 `&nbsp;` 占位。

### 坑 8：Graphviz 的 `splines=ortho` 不支持边标签
- **现象**：`Warning: Orthogonal edges do not currently handle edge labels.`，标签被丢掉、布局变得很乱。
- **修复**：别用 `splines=ortho`；层级图用默认 spline + 分块（表格标签）布局更清楚。

### 坑 9：Graphviz 渲染中文必须显式指定字体
- 不指定 `fontname="Microsoft YaHei"` 时中文会渲染成方框。
  `graph` / `node` / `edge` 三处都要设。

### 坑 10：生成 docx 时文件被 Word 占用
- **现象**：`Permission denied`。目录里出现 `~$xxx.docx` 即说明 Word 正开着。
- **处理**：先关 Word；或先输出到别的文件名，稍后再覆盖。

## 五、已知限制

- `md2thesis.py` 目前支持：标题 4 级、段落、列表、简单表格、下划线填空、目录、页码。
  **不支持**：图片插入、多级列表自动编号（如 `1.1.1`）、公式、脚注。
  论文阶段若要插图，用 `python-docx` 的 `add_picture` 扩展脚本即可。
- `add_toc.py` 依赖本机 Word（COM）。换电脑若无 Office，目录将停留在占位文字。
- `gen_diagrams.py` 的层级位置由 Graphviz 自动布局，节点数量大改时需微调 `ranksep` / `nodesep`。
- PPT 与 ER 图脚本用的是固定版式，内容量大改需同步调整参数。
