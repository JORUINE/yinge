## 一、这是什么

**音格**是一个用「对决」和「测评」两种玩法，帮你选出最爱的专辑、并测出你音乐人格的互动网站。

- **专辑对决**：输入一位歌手，系统自动抓出他的全部专辑，两两对决、逐轮淘汰，最终选出你的冠军专辑，并生成一张「夺冠之路」对战图。
- **音乐人格测评**：12 道题（含听感题）测出你的音乐人格类型，生成可分享的人格卡，并由大语言模型生成个性化解读。

两个玩法共用同一套底层（音乐数据、用户系统、分享图引擎、排行榜）。

## 二、技术栈

| 层次 | 选型 |
|------|------|
| 前端 | Vue 3 · Vite · Vue Router · Pinia · Element Plus · Axios |
| 后端 | Node.js · Express |
| 数据库 | MongoDB · Mongoose |
| 认证 | JSON Web Token · bcrypt |
| 分享图 | DOM 转图片方案 |
| 音乐数据 | iTunes Search API（免密钥） |
| 文本生成 | 大语言模型接口 |
| 部署 | 前端静态托管 + 后端云托管 + 云数据库 |

## 四、本地启动

> 依赖安装完成前请先执行 `npm install`。

**后端**

```bash
cd backend
npm install
npm run dev          # 默认 http://localhost:3000
```

**前端**

```bash
cd frontend
npm install
npm run dev          # 默认 http://localhost:5173
```

## 五、环境变量

> 请勿把密钥提交到仓库。本地开发请复制 `.env.example` 为 `.env` 后填写。

| 变量名 | 说明 | 必填 |
|--------|------|------|
| `PORT` | 后端服务端口，默认 3000 | 否 |
| `MONGODB_URI` | MongoDB 连接字符串 | 是 |
| `JWT_SECRET` | JWT 签名密钥 | 是 |
| `LLM_API_KEY` | 大语言模型接口密钥 | 是 |
| `LLM_BASE_URL` | 大语言模型接口地址 | 否 |
| `CORS_ORIGIN` | 允许跨域的来源，逗号分隔 | 是 |
| `ITUNES_COUNTRY` | 音乐数据地区，默认 `cn` | 否 |

## 六、数据来源说明

音乐元数据与 30 秒试听片段来自 **iTunes Search API**：

- 无需密钥、无需账号授权，可直接调用
- 提供歌手、专辑、曲目元数据与官方试听片段（`previewUrl`）
- 音频由 Apple 官方服务器提供，本项目不存储、不分发任何音频文件
- 本项目仅将公开接口返回的数据用于展示，并缓存于自己的数据库中
